# T-09 — refs/n8n: os fluxos como referência de schema

## 1. Objetivo
Depois de você terminar, existe `refs/n8n/` com os fluxos F1 e F2
exportados da instância que está rodando, **sem credencial e sem id de
instância**, mais um README que diz o que cada nó ensina.

## 2. Caminhos absolutos
- criar: `/home/nicolas/Área de trabalho/esteira/refs/n8n/` (a pasta está vazia hoje)
- fonte: `/home/nicolas/Área de trabalho/esteira/n8n/esteira-comms-out.json` e `/home/nicolas/Área de trabalho/esteira/n8n/esteira-comms-in.json`
- leia: `/home/nicolas/Área de trabalho/esteira/refs/README.md` — ele explica **por que** esta pasta é "a de
  maior retorno do projeto" e o que sanitizar
- leia: `/home/nicolas/Área de trabalho/esteira/n8n/README.md` — a especificação dos 4 fluxos
- n8n rodando: `http://localhost:5678`
- binário: `/home/nicolas/.nvm/versions/node/v24.18.0/bin/n8n`

## 3. Escopo
Só `refs/n8n/**`. Qualquer arquivo fora disso é violação.
**Não escreva nada fora do repo.** Nem em `~/`, nem em `/tmp` a não ser
como rascunho descartável.

## 4. O que NÃO tocar
`n8n/**` (os fluxos de produção são a fonte, não o alvo) · `esteira/**` ·
`demands/**` · `deploy/**` · qualquer `.env` · o banco do n8n em `~/.n8n`.

## 5. Prova exigida
Para **cada** arquivo que você criar em `refs/n8n/`:

    export PATH="$HOME/.nvm/versions/node/v24.18.0/bin:$PATH"
    n8n import:workflow --input="refs/n8n/<arquivo>.json" ; echo "saida=$?"

Tem que sair **0**. Cole as saídas. Fluxo que não importa não é referência
de nada — o `refs/README.md` avisa exatamente isso.

E prove que sanitizou:

    grep -inE '"(value|token|password|clientSecret|apiKey|accessToken)"\s*:\s*"[^"=]{8,}"' refs/n8n/*.json

Tem que voltar vazio (as expressões `={{ ... }}` são referência, não
segredo — se aparecer alguma, explique no README por que é inofensiva).

## 7. Detalhes que importam
- O valor desta pasta é **schema**, não lógica: o próximo agente que
  precisar gerar fluxo n8n copia a forma dos nós daqui em vez de chutar
  `typeVersion` e `connections` — que é o que faz o JSON gerado "nem
  abrir", segundo o `refs/README.md`.
- Por isso o README de `refs/n8n/` é metade do entregável. Para cada nó
  interessante, diga **o que ele ensina**: como um `switch` roteia por
  campo, como um `code` recebe `$input`, como um `microsoftOutlook`
  referencia credencial por nome, como `connections` liga saída numerada.
- **Anote a versão.** `n8n 2.36.8`. Fluxo de referência sem versão
  envelhece sem ninguém notar — o `refs/README.md` pede o commit anotado
  pelo mesmo motivo.
- Credencial nunca no JSON. Referência de credencial **por nome** pode e
  deve ficar — é o que ensina o formato.
- PT-BR. Palavra estrangeira em itálico no README.
